    NovaPlatform

    Ein Full-Stack-Webshop für digitale Produkte: ein Java/Spring-Boot-Backend, das eine Shop-Oberfläche in reinem JavaScript bereitstellt, Kundenkonten über Supabase, Administrationsoberflächen und E-Mail-Versand. Umgesetzt mit KI-gestützter Implementierung.

    Überblick

    NovaPlatform ist eine Webanwendung für den Verkauf digitaler Produkte, entwickelt als Beta-Version. Für Kunden umfasst der Code einen Spielekatalog, Checkout, Anmeldung, Bestellübersicht und Supportanfragen; für das Team gibt es eigene Administrationsoberflächen für Katalog, Lagerbestand, Bestellungen und Support.

    Schwerpunkte

    • Shop und KundenkontenSpielekatalog, Checkout, Anmeldung und Bestellübersicht.
    • AdministrationsoberflächenGetrennte Bereiche für Katalog, Lager, Bestellungen und Support.
    • Transaktionale E-MailsKonto-E-Mails über Supabase, weitere über das Backend.
    • Docker-PaketierungAls Docker-Image mit Deployment-Anleitung.

    Architektur

    Eine einzelne Spring-Boot-Anwendung stellt sowohl die REST-API als auch das statische Frontend bereit, das mit HTML, CSS und reinem JavaScript umgesetzt ist. Supabase liefert die PostgreSQL-Datenbank und die Kundenauthentifizierung; Schemaänderungen werden als nummerierte SQL-Migrationen verwaltet.

    Konto-E-Mails wie die Registrierungsbestätigung und das Zurücksetzen des Passworts laufen über Supabase Authentication mit eigenen Vorlagen; weitere E-Mails versendet das Backend über einen externen E-Mail-Dienst. Der Admin-Zugang ist von den Kundenkonten getrennt. Im Code sind dafür gehashte Passwörter, eine Begrenzung der Login-Versuche und Sicherheits-Header umgesetzt. Das Repository enthält einen Docker-Build und eine Anleitung für das Deployment bei einem Cloud-Anbieter.
