    Overview

    NovaPlatform is a web application for selling digital goods, developed as a beta. For customers, the codebase covers a game catalog, checkout, sign-in, order history and support requests; for staff, separate admin panels manage the catalog, stock, orders and support.

    Architecture

    A single Spring Boot application serves both the REST API and the static frontend, which is written in HTML, CSS and plain JavaScript. Supabase provides the PostgreSQL database and customer authentication; schema changes are kept as numbered SQL migrations.

    Account emails, such as sign-up confirmation and password reset, are sent by Supabase Authentication with custom templates; other emails are sent by the backend through an external email service. Admin access is separate from customer accounts. For it, the code implements hashed passwords, login rate limiting and security headers. The repository includes a Docker build and deployment notes for a cloud host.

The release notes record specific fixes, for example a mobile menu that appeared in the wrong place in Android Chrome and in-app browsers; it was moved out of the sticky header to avoid the rendering bug.
